**Safety-first clinical question answering**

A clinical RAG backend for asthma-related questions grounded in GINA, NICE NG80, and NHLBI guidelines.

- Hybrid retrieval and reranking
- Evidence gating and citation validation
- Safety-oriented refusal mechanisms
- AWS deployment

`Python` `FastAPI` `pgvector` `Cohere` `Celery` `Docker`

[Repository →](https://github.com/mo22zy2/RAG_AI_Hackathon)

### 🧠 Sentra MCP
**From lecture PDFs to realistic mock exams**

An open-source MCP server that transforms lecture materials and past exams into structured study material and practice exams.

- Local-first workflow
- MCP-compatible AI coding clients
- Grounded outputs with source references
- Automated multi-stage processing pipeline

`Python` `MCP` `uv` `pytest`
